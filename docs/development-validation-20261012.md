# 按方案继续开发：资料与会议生命周期

2026-10-12，开发分支 `feat/meeting-workbench`。本轮接续第一版工作台，未访问生产服务器或修改其他项目。

## 完成的行为

1. **私有附件**：网页上传默认私有，报价底线等不再只能放在简短私有笔记里。共享/私有属性同时约束资料列表、原文件下载、变化回放和模型上下文。客户受众永远不读取私有附件；Agent 需要相应私有权限，不能公开或删除文件。
2. **分析范围**：每份资料独立选择参与下一次 AI 分析，取消选择保留原文件与文字。可以用这一操作排除无关的大附件，避免反复命中单次上下文预算。没有实现检索压缩；超长会议记录仍明确返回预算错误，原文不裁切。
3. **资料管理**：共享设置和分析选择使用 revision 校验，冲突不覆盖。人类确认删除会清理原件、提取文字和资料回放历史；其他标签页实时移除卡片。已有建议和引用不会自动清除，界面在删除前明确说明。
4. **持续发言**：保留 1.4 秒去抖，增加八秒最大等待，避免发言持续到来时一直不分析。若同会前一请求正在执行则等待，人工求助仍优先。
5. **会议结束**：停止收音，关闭并取消自动分析。历史记录仍可查看、修订、导出与手动求助。继续会议不会自动重启自动建议；状态由人类控制。
6. **升级兼容**：第一版 SQLite 自动补齐资料可见性、分析选择和修订字段；旧资料保留原共享属性。REST 上传省略 visibility 保持原 shared 行为，网页显式提交 private。未自动迁移旧 JSON 或旧培训数据库。
