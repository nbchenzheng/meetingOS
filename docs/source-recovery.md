## 安装、构建与启动验证

在独立干净副本中使用 Node 24.19.0 / npm 11.9.0，删除业务数据，仅保留静态角色配置，然后执行：

```bash
npm ci --ignore-scripts --no-audit --no-fund --cache /tmp/meetingos-npm-cache
npm run build
```
