# ai-board 增量 PRD：妙记竞品借鉴点落地（全量 P0+P1+P2）

> **文档类型**：增量 PRD（仅描述本次变更）
> **语言**：中文
> **基线**：双标签（发言区 + 智能纪要）；后端已有实时转写(DeepSeek)、AI整理版(refinedText)、思维导图、大咖AI主动点评
> **复用组件**：`TranscriptPanel` / `MindMap` / `CommentaryPanel`（不重写，仅扩展）
> **硬约束**：纯文字流，无音视频录制/回放；无企业通讯录/真实参会人体系；保留特殊角色"大咖AI"（拟人化 AI 顾问）
> **明确排除**：音字同步播放、视频片段分享+权限、@真实同事+任务系统联动、声纹识别、导出视频、多语言翻译

---

## 1. 变更目标

将飞书妙记竞品研究中确认可借鉴的能力（全局搜索、结构化纪要、角色可视化、来源标注、标签、划词、导出、占比条、移动端）增量落地到现有双标签架构，提升纯文字流会议记录的**可检索性、可读性与可协作性**，全程不引入音视频与真实通讯录体系。

---

## 2. 用户故事

1. **全局检索**：作为一名参会者，我希望在顶部搜索框输入关键词即可跨"发言区+智能纪要三区块"查找，并从结果列表一键跳到对应位置并高亮，以便快速定位关键信息。
2. **结构化纪要**：作为一名复盘者，我希望 AI 整理版按「章节 + 结论句高亮 + 独立行动项」呈现，以便一眼看清讨论脉络与待办。
3. **角色可视化与重命名**：作为一名读者，我希望每条发言前有角色配色圆点、且能在会话内重命名"张总/麦克风1"，以便区分多位真人及大咖AI。
4. **来源可追溯**：作为一名纪要使用者，我希望纪要每段标注"源自 发言区 03:12 张总"并可点跳回原句，以便核查结论出处。
5. **关键词高亮**：作为一名速读者，我希望系统提炼关键词、点击即在全文高亮全部命中并支持上/下跳转，以便把握重点。
6. **标签聚合**：作为一名组织者，我希望给发言打"结论/待办/疑问/重点"标签，并通过顶部 Tab 聚合同类句子成清单，以便分主题跟进。
7. **行内纠错**：作为一名记录者，我希望 hover 出 ✎ 直接修正某句转写错字，保存后标"已编辑"且不改时间戳，以便修正错别字。
8. **导图下钻**：作为一名决策者，我希望点击思维导图节点展开"该议题的发言来源/大咖观点"并跳回发言区，以便从结论回溯论据。
9. **划词协作**：作为一名协作者，我希望选中文字弹出工具条做高亮/评论/引用，评论进入实时点评流，以便轻量协同。
10. **导出归档**：作为一名归档者，我希望一键导出 Markdown/TXT（含角色与相对时间戳），以便会后留档与外发。
11. **移动端查阅**：作为一名移动用户，我希望在手机上仍能正常使用双标签、搜索、占比条与导出，以便随时回顾。

## 4. UI 设计稿（结构化描述 + ASCII）

### 4.1 全局搜索框 + 结果面板
- **位置**：应用 topbar 中部（与"导出"按钮并列）；支持 `⌘K` 唤起聚焦。
- **形态**：输入即出下拉结果面板（非模态，覆盖在内容之上），分组展示命中来源。

```
┌──────────────────────────────────────────────────────────────┐
│ [≡] ai-board     🔍 [ 搜索发言 / 纪要 / 导图…      ] ⌘K   [导出]│  ← topbar
├──────────────────────────────────────────────────────────────┤
│ 搜索 “预算”  (4)                              [×]             │
│ ┌────────────────────────────────────────────────────────┐  │
│ │ 💬 发言区  03:12 张总   "关于 Q3 预算我们建议…"        │  │
│ │ 💬 发言区  03:30 大咖AI "预算可分两批执行〔AI补充〕"   │  │
│ │ 📝 智能纪要·章节二  "结论：预算下调 10%"  ⮕结论高亮   │  │
│ │ 🧠 思维导图·节点"降本"  → 点击下钻来源               │  │
│ └────────────────────────────────────────────────────────┘  │
│  ↑/↓ 选择 · Enter 跳转并高亮                                  │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 结构化纪要区块
- 复用"智能纪要"三区块 Tab，仅在 `refinedText` 全文区做内部升级；新增「✅ 行动项」独立子区块。

```
┌─ 智能纪要 ───────────────────────────────────────────┐
│ [全文] [思维导图] [实时点评]   ← 现有三区块 Tab        │
│ ┌─ refinedText（结构化）──────────────────────────┐  │
│ │ ▾ 一、Q3 预算讨论                              │  │
│ │   • 张总提出预算需下调 ➜ ║结论句高亮║          │  │
│ │   • 大咖AI建议分批执行        〔AI补充〕        │  │
│ │ ▾ 二、人员安排                                   │  │
│ │ ┌─ ✅ 行动项 ─────────────────────────────┐   │  │
│ │ │ ☐ 张总  周五前提交预算表  (源自 03:12)   │   │  │
│ │ │ ☐ 李工  评估降本方案      (源自 05:40)   │   │  │
│ │ └─────────────────────────────────────────┘   │  │
│ └───────────────────────────────────────────────┘  │
│ [🔑 关键词: 预算 · 降本 · 排期]   ← P1-③ 展示区    │
└──────────────────────────────────────────────────────┘
```

### 4.3 角色配色圆点 + 会话级重命名
- 发言区每条前加圆点；大咖AI 专属渐变；真人统一灰标或麦克风色；`▾` 触发重命名浮层（仅会话内）。

```
发言区每条:
●张  [张总 ▾]   03:12  "关于 Q3 预算我们…"        ← 灰圆点+首字母, ▾重命名
🌈   [大咖AI ▾] 03:30  "建议分两批执行"           ← 专属渐变圆点
●李  [李工 ▾]   05:40  "我来评估降本方案"         ← 另一真人灰标
```

### 4.4 标签筛选 Tab
- 发言区顶部横向 Tab；标记后句左侧出现彩色标签条；点 Tab 切换"全部 / 单标签聚合清单"。

```
发言区顶部:
[ 全部 ] [🟢结论] [🔵待办] [🟡疑问] [🔴重点]   ← 筛选 Tab
─────────────────────────────────────────
●张 🟢 03:12 "预算需下调"        ← 左侧彩色标签条
●李 🔵 05:40 "评估降本方案"     ← 待办条
(点 [🟢结论] → 仅列出所有🟢句成清单)
```

### 4.5 划词工具条
- 选中文字浮现迷你工具条；"评论"走 CommentaryPanel；"高亮"会话内常驻。

```
在发言区/refinedText 选中文字时:
        ┌─────────────────┐
        │ 高亮 │ 评论 │ 引用 │
        └─────────────────┘
                  │
            "评论" → CommentaryPanel（可 @大咖AI / 留名）
            "高亮" → 持久高亮（会话态）
```

### 4.6 文字摘录卡片（P2）
- 多选句子后浮现入口；生成卡片可复制/导出。

```
选中多句 → 浮现 [生成摘录卡片]
┌─ 摘录卡片 ────────────────┐
│ +03:12 张总: 预算需下调…  │
│ +03:30 大咖AI: 分两批…    │
│ [复制 MD]   [导出]        │
└──────────────────────────┘
```

### 4.7 发言占比条（P2）
- topbar 或发言区顶部；按角色着色；点击段筛选/跳转。

```
角色发言占比条:
[ ●张 45% ][ 🌈大咖AI 30% ][ ●李 25% ]
 ↑点击该段 → 筛选/跳转 张总 全部发言
```

```
┌─ 顶部: 🔍搜索 [☰菜单] 📊占比 ─┐
├─ Tab: [ 发言区 ] [ 智能纪要 ]  │
│   智能纪要内: [全文][导图][点评]│
│   标签筛选: 横向滚动 ◀🟢🔵🟡🔴▶ │
```

## 5. 待确认问题（需架构师 / 用户拍板）

1. **结构化纪要后端 JSON Schema**：章节 / 结论 / 行动项 的字段定义如何设计？是否嵌套原文锚点 `entryId`、行动项 `owner`/`due` 由 AI 推断还是留空？
2. **关键词抽取归属与输出格式**：由后端 DeepSeek 抽取（推荐，质量高）还是前端正则/词频？输出结构（词 + 出现位置/频率）？
3. **来源锚点回带方式**：后端在整理时关联原文 `entryId`（首选，精准）还是前端文本匹配兜底？该决策同时影响 P0-② / P1-② / P1-⑥。
4. **移动端断点**：是否沿用 720px 单一断点，还是各组件分别断点？
5. **大咖AI 固定视觉**：占比条/配色/圆点中是否始终置顶？专属渐变具体色值？是否计入"角色"统计口径？
6. **（补充）持久化边界**：行内编辑、划词高亮、标签、重命名是仅会话内存（local state）还是落库？刷新/重开会议是否保留？
7. **（补充）跨端一致性**：标签与重命名若需跨端同步则必须后端存储，否则可纯前端会话态——是否接受纯前端方案？
